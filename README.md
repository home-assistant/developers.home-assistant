# This repository has moved

As of October 16, 2026, the Home Assistant developer documentation lives at **[contributors.home-assistant.io](https://contributors.home-assistant.io)**: one site for everyone who contributes to Home Assistant, code or no code. It replaces developers.home-assistant.io, design.home-assistant.io, and data.home-assistant.io.

- Read the documentation at [contributors.home-assistant.io](https://contributors.home-assistant.io).
- Open issues and pull requests at [home-assistant/contributors.home-assistant.io](https://github.com/home-assistant/contributors.home-assistant.io).

Old links to developers.home-assistant.io, including the blog, redirect to their new home.

This repository is kept for its history and is no longer maintained. Changes made here won't be published.
